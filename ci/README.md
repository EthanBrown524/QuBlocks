# ci/

`cross_validate.py` (not yet written) will install Qiskit/Cirq in Python,
execute the code generated by `@qublocks/compiler-qiskit` and
`@qublocks/compiler-cirq` for each preset program, and diff the resulting
statevector against `@qublocks/simulator`'s TypeScript output within
floating-point tolerance.

This is CI-only — it never ships and never runs in the browser. It's what
proves the compiler backends are correct rather than merely
plausible-looking.
